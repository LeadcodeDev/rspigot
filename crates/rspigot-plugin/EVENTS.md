# Plugin events

Generated by `tools/gen_plugin_events.py` from `tools/plugin-events/catalog.json` (the Spigot API jar) and `tools/plugin-events/overrides.toml`. Do not edit.

251 events, 211 decidable, 185 cancellable, 116 with setters. 34 are fired by the server today; the others have their types and wait for their fire point.

An observing handler takes `&Event`. A deciding handler takes `&mut Event` and exists only for a decidable event (cancellable or with setters). `cancel()` exists only on a cancellable event. A handler also receives the events of the classes that share its Bukkit handler list and extend its event (column "Also receives"), as its own type.

`CraftItem`, `InventoryClick`, `InventoryCreative`, `InventoryDrag`, `PlayerInteract`, `SmithItem`, `TradeSelect` are cancelled through their result, as in Bukkit: `cancel()` sets `result`, `use_interacted_block`, `use_item_in_hand` to `Deny`, `is_cancelled()` reads the main result only, and a later handler that sets the result back lifts the cancel.
